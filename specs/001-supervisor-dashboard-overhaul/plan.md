# Implementation Plan: Supervisor Dashboard Overhaul

**Branch**: `001-supervisor-dashboard-overhaul` | **Date**: 2026-05-17 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/001-supervisor-dashboard-overhaul/spec.md`

---

## Summary

Replace all hardcoded placeholder data in the Supervisor Dashboard with live Supabase
queries (Active Units, Completed Tasks, Delayed Tasks, Reports Today, and Live Task
Summary percentages). Implement the Assign Task bottom sheet end-to-end with flight /
service-type / unit dropdowns and a Reset button. Add supervisor-level report deletion
with a confirmation dialog and optimistic UI. Polish the entire dashboard to production
quality: shimmer skeletons, dark mode fidelity, RTL support, and `flutter_animate`
micro-animations.

Architecture: Flutter MVVM + Modular Architecture, BLoC/Cubits for state, Supabase
(PostgREST) as backend, GetIt for DI. All code lives in
`lib/modules/supervisor/features/dashboard/` and must follow the
`data/remote → data/repo → logic/cubit → ui` layered layout.

---

## Technical Context

**Language/Version**: Dart 3.x / Flutter 3.x

**Primary Dependencies**: flutter_bloc ^9.1.1, supabase_flutter ^2.10.3, get_it ^9.0.5,
flutter_screenutil ^5.9.3, flutter_animate ^4.5.2, easy_localization ^3.0.8

**Storage**: Supabase (PostgreSQL via PostgREST) — tables: `units`, `tasks`, `reports`,
`flights`, `stands`, `service_types`

**Testing**: `make test` (Flutter test suite — unit tests for cubits)

**Target Platform**: Android + iOS mobile

**Project Type**: Mobile app — supervisor role module

**Performance Goals**: Dashboard stats load ≤ 2s; Assign Task sheet ready ≤ 1.5s;
report delete ≤ 1s (optimistic)

**Constraints**: All sizes via `.w/.h/.sp/.r`; all strings via `.tr()`; no direct
Supabase client access outside Remote Data Sources; no raw pixel values; no inline
`Color(...)` or `TextStyle(...)`

**Scale/Scope**: Airport-wide queries (global, not supervisor-scoped in this iteration);
expected row counts: units <100, tasks/day <500, reports/day <200, flights/day <100

|-----------|------|--------|
| I. Modular Role-Based Architecture | All new files live in `lib/modules/supervisor/features/dashboard/` or `lib/modules/supervisor/features/reports/`. No code crosses into worker/admin modules. Shared models used from `lib/core/shared/data/` only. | ✅ PASS |

| V. Localization-First | New strings namespaced `supervisor_dashboard.*` in both `en.json` and `ar.json`. RTL verified via `context.isArabic`. No hardcoded English strings in widgets. | ✅ PASS |

### Layer 3 — Cubits

#### SupervisorDashboardCubit

```
Events (methods):
  loadDashboard()       → fetch stats + task summary in parallel (Future.wait)
  refresh()             → same as loadDashboard(), called by pull-to-refresh

State transitions:
  initial → loading → success (stats + summary populated)
                    → failure (AppError emitted)
```

#### AssignTaskCubit

```
Events (methods):
  loadFormData()         → fetch flights + units + serviceTypes in parallel
  selectFlight(id)       → update selectedFlight, clear unit selection
  selectServiceType(id)  → update selectedServiceType, recompute filteredUnits
  selectUnit(id)         → update selectedUnit
  setPriority(p)         → update priority
  setScheduledStart(dt)  → update scheduledStart, validate against scheduledEnd
  setScheduledEnd(dt)    → update scheduledEnd, validate against scheduledStart
  setNotes(text)         → update notes
  reset()                → emit initial AssignTaskState (keep form open)
  submit()               → validate → submit → emit success or failure

State transitions:
  initial → loadingFormData → formReady
                           → failure (form data load failed)
  formReady → submitting → success
                        → failure (submission error)
```

#### SupervisorReportsCubit

```
Events (methods):
  loadReports()          → fetch all reports ordered by created_at DESC
  deleteReport(String id) → optimistic remove → Supabase delete → rollback on error

State transitions:
  initial → loading → success (reports list)
                    → failure
  success → deleting (optimistic removal) → success (confirmed)
                                          → failure (rollback + show error)
```

### Layer 4 — UI Changes

#### supervisor_dashboard_screen.dart

- Wrap `ListView` content in `BlocConsumer<SupervisorDashboardCubit, SupervisorDashboardState>`.
- On `loading`: show shimmer skeleton list.
- On `success`: render real widgets.
- On `failure`: show inline error card with retry button that calls `cubit.loadDashboard()`.
- `RefreshIndicator.onRefresh` calls `cubit.refresh()` instead of `Future.delayed`.

#### supervisor_status_grid.dart

- Read counts from `context.read<SupervisorDashboardCubit>().state.stats`.
- On loading state: replace `_StatCard` with `_StatCardSkeleton` (shimmer via `flutter_animate`).
- Count-up animation on value change: use `flutter_animate`'s `.animate().fadeIn()` on
  the value `Text`.

#### supervisor_live_task_summary.dart

- Read percentages from `state.taskSummary` (computed `donePct`, `inProgressPct`, `delayedPct`).
- Show empty-state message when `taskSummary.isEmpty`.
- On loading: shimmer over the progress bar area.

#### supervisor_quick_actions_row.dart

- "Assign Task" `onTap` → `showModalBottomSheet(context, builder: (_) => BlocProvider(
    create: (_) => AssignTaskCubit(getIt<SupervisorDashboardRepo>())..loadFormData(),
    child: const AssignTaskBottomSheet(),
  ))`.
- After successful assignment: close sheet, call `dashboardCubit.refresh()`.

#### assign_task_bottom_sheet.dart (NEW)

- `DraggableScrollableSheet` with min extent 0.6, max extent 0.95.
- Sections: Flight dropdown, Service Type dropdown, Unit dropdown (filtered), Priority
  selector (chip row: Low/Medium/High/Critical), Start time picker, End time picker,
  Notes text field (optional), Submit button, Reset button.
- `BlocConsumer<AssignTaskCubit, AssignTaskState>`:
  - On `loadingFormData`: shimmer over dropdown fields.
  - On `submitting`: disable Submit + show inline loader.
  - On `success`: `Navigator.pop(context)`.
  - On `failure`: show error snack bar, keep sheet open.
- Reset button: calls `cubit.reset()`, re-runs `cubit.loadFormData()`.

#### supervisor_reports_screen.dart (MODIFIED)

- Add `BlocConsumer<SupervisorReportsCubit, SupervisorReportsState>`.
- Wrap each report list item in `Dismissible` (swipe-to-delete, direction: `endToStart`).
- On dismiss: show `AppDialogs.confirm()` before calling `cubit.deleteReport(id)`.
- On `deleting`: show delete spinner overlay on the specific item.
- On `failure`: show error snack bar + rollback (item reappears).

#### supervisor_scaffold.dart (MODIFIED)

Add to `MultiBlocProvider`:
```dart
BlocProvider(create: (_) => getIt<SupervisorDashboardCubit>()..loadDashboard()),
BlocProvider(create: (_) => getIt<SupervisorReportsCubit>()..loadReports()),
```
