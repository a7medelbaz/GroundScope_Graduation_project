## Summary

Replace the `AssignTaskBottomSheet` (modal bottom sheet with a skeleton loading state) with a dedicated full-page screen (`AssignTaskScreen`) navigated to via a named route. The new screen uses a full-screen `CircularProgressIndicator` during data loading, a `cloud_off` error state with retry, and the existing form layout — all consistent with the app design system. No cubit or repository logic changes; this is a pure presentation-layer and navigation change.

## Implementation Design

### 1. Route Constant (`routes.dart`)

Add:
```dart
static const String supervisorAssignTaskScreen = '/supervisorAssignTaskScreen';
```

### 2. DI Registration (`dependency_injection.dart`)

Add a factory registration so the cubit is resolved fresh on each navigation:
```dart
getIt.registerFactory<AssignTaskCubit>(
  () => AssignTaskCubit(
    repo: getIt<SupervisorDashboardRepo>(),
    userService: getIt<UserService>(),
  ),
);
```

### 3. Router Case (`app_routers.dart`)

```dart
case Routes.supervisorAssignTaskScreen:
  return _buildRoute(
    BlocProvider(
      create: (_) => getIt<AssignTaskCubit>()..loadFormData(),
      child: const AssignTaskScreen(),
    ),
    settings,
  );
```

Import: `import '../../modules/supervisor/features/dashboard/ui/assign_task_screen.dart';`

### 4. Quick Actions Row (`supervisor_quick_actions_row.dart`)

Replace `_openAssignTask`:
```dart
void _openAssignTask(BuildContext context) {
  context.pushNamed(
    Routes.supervisorAssignTaskScreen,
    rootNavigator: true,
  );
}
```

Remove import of `assign_task_bottom_sheet.dart`, `get_it`, and the inline `BlocProvider`. Add import of `Routes`.

### 5. Assign Task Screen (`assign_task_screen.dart`) — NEW FILE

**Design system compliance** (user requirement: "consistent with app design"):

| Element | Spec |
|---|---|
| App bar | `CustomAppBar(title: 'supervisor_dashboard.assign_task_title'.tr())` — used in `Column` body, not `Scaffold.appBar` |
| Loading state | `Center(child: CircularProgressIndicator(color: AppColors.primary200))` — design system §8 Pattern A |
| Error state | `cloud_off_rounded` `rf(48)` `cc.textDisabled` + `font14Light` message + `TextButton.icon(Icons.refresh_rounded)` retry |
| Form inputs | `InputDecoration` with `filled: true`, `cc.surface`, `OutlineInputBorder(rr(12))` — matching existing `_inputDecoration` |
| Section labels | `font14SemiBold`, `cc.textSecondary` |
| Priority chips | Row of tappable chips: selected bg `color @ 0.15`, border `color`, text `color`; unselected bg `cc.surface`, border `cc.border @ 0.5`, text `cc.textHint` |
| Time pickers | `showTimePicker` + styled container `cc.surface`, `rr(12)`, clock icon `rf(18)` |
| Reset button | `OutlinedButton` with `cc.border` side, `rr(12)`, `font16SemiBold` `cc.textSecondary` |
| Submit button | `FilledButton` with `AppColors.primary200` bg, `rr(12)`, `font16SemiBold` white; disabled at `primary200 @ 0.4`; loading shows `CircularProgressIndicator` 20×20 white |
| Scroll | `SingleChildScrollView` with `physics: const BouncingScrollPhysics()`, padding `EdgeInsets.fromLTRB(rw(20), rh(8), rw(20), rh(32))` |
| Background | `cc.background` |

**BlocConsumer listener** (success path order matters):
```dart
if (state.status == AssignTaskStatus.success) {
  context.read<SupervisorDashboardCubit>().refresh(); // async, non-blocking
  context.showSuccessSnackBar('supervisor_dashboard.task_assigned_success'.tr());
  context.pop();
}
```

**Screen structure**:
```
Scaffold(backgroundColor: cc.background)
└── SafeArea(top: false)
    └── Column
        ├── CustomAppBar(title: assign_task_title)
        └── Expanded
            └── BlocConsumer<AssignTaskCubit, AssignTaskState>
                listener: success → refresh + snackbar + pop
                          failure + error != null → showErrorSnackBar
                builder:
                  loadingFormData → Center(CircularProgressIndicator)
                  failure + flights.isEmpty → _ErrorBody(onRetry: loadFormData)
                  _ → _FormBody (SingleChildScrollView with all fields + buttons)
```

**Private widgets** (moved from `assign_task_bottom_sheet.dart`, adjusted for full-page context):
- `_ErrorBody` — cloud_off error state
- `_FormBody` — the scrollable form
- `_SectionLabel` — field label text
- `_PriorityChipRow` — priority selection row
- `_TimePicker` — time picker field
